# External User Guide

This repository’s **external / customer** documentation lives in the distribution package:

**[distribution/README.md](distribution/README.md)**

That file is what external users receive inside `rdp-in-browser-distribution.zip`. It covers:

- Installing and starting the app with Docker (no source code)
- First-time admin setup
- End-user remote desktop usage
- Shared drive file exchange (`DRIVES_PATH`)
- Backup, updates, and troubleshooting
